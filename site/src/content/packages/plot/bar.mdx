# Bar

A bar series represents values as bars, making it easy to compare categories
and see their relative sizes. Use a categorical field on one axis and a numeric
field on the other. Categories on `x` produce vertical bars, while categories
on `y` produce horizontal bars.

## Rounded bars and data colors

Set corner rounding and spacing independently. A color accessor highlights days with more than 80 requests per second.

<Preview minHeight={308}>
  <PlotBarPreview example="rounded" />
</Preview>

```js folded
const data = [
    { day: 'Mon', requests: 42 },
    { day: 'Tue', requests: 68 },
    { day: 'Wed', requests: 91 },
    { day: 'Thu', requests: 57 },
    { day: 'Fri', requests: 84 },
    { day: 'Sat', requests: 36 },
    { day: 'Sun', requests: 24 },
  ]

  const rounded_bars = plot({
    series: [plot.bar({
        data,
        x: 'day',
        y: 'requests',
        border_radius: 6,
        inset: 5,
        color: pure(row => Number(row.requests) > 80
          ? { light: '#c2410c', dark: '#fdba74' }
          : { light: '#0891b2', dark: '#67e8f9' }),
        hover_span_x: true,
        tooltip: pure(({ x, y }) => h("span", {}, x + ': ' + y + ' requests/s')),

    height: 260,

    axis: { x: { label: '' }, y: { min: 0, max: 100, label: '' } },
```

## Bar arguments

<div class="plot-table-heading">

### BarArgs

</div>

| Field | Type | Default | Description |
|---|---|---|---|
| `data` | `{[key: string]: any}[]` | Required | Data points to plot. |
| `x?` | [`FieldArg \| string[]`](/plot/#data-fields) | `'x'` | Category or value field. An array of value fields creates horizontal stacks. |
| `y?` | [`FieldArg \| string[]`](/plot/#data-fields) | `'y'` | Category or value field. An array of value fields creates vertical stacks. |
| `color?` | [`ColorArg`](/plot/#series-colors) or [`ThemeColor[]`](/plot/#theme-colors) | Black | Uniform or per-row color. A color array maps to stacked fields in order. |
| `border_radius?` | `number` | `0` | Bar corner radius in pixels. |
| `inset?` | `number` | 1/6 of band width | Space left on each side within a categorical band, in pixels. |
| `min_size?` | `number` | `2` | Minimum rendered value length in pixels. |
| `hover_span_x?` | `boolean` | `false` | Extend the area that responds to tooltips, selection, and hover highlights along the x axis. |
| `hover_span_y?` | `boolean` | `false` | Extend the area that responds to tooltips, selection, and hover highlights along the y axis. |
| `tooltip?` | [`TooltipArg`](/plot/#tooltips) | None | Use `true` for the default tooltip, or a callback for custom content. |
| [`on_select?`](/plot/#selection) | `SelectFn` | None | Callback receiving the selected point and its source data. |
| `hoverable?` | `boolean` | `true` | Enable tooltips, selection callbacks, and hover highlights for this series. |
| `highlight?` | `boolean` | `true` | Highlight a data point when you hover over it. |
| `highlight_color?` | [`ColorArg`](/plot/#series-colors) | Automatic | Exact hover color, including opacity. Stacked bars also accept a `ThemeColor[]` palette. |

This example draws a bar for each `group` using its `count`, rounds the corners, and adds tooltips and a selection callback.

```js
const selected_data = new reactive.StateVar('Select a point to inspect its data.')

  const series = [plot.bar({
      data: [{ group: 'A', count: 8 }, { group: 'B', count: 12 }],
      x: 'group',
      y: 'count',
      color: { light: 'steelblue', dark: 'lightskyblue' },
      border_radius: 3,
      inset: 4,
      min_size: 2,
      hover_span_x: true,
      hover_span_y: false,
      tooltip: pure(({ x, y }) => h("span", {}, `(${x}, ${y})`)),
      on_select: pure(({ row }) => selected_data.set(JSON.stringify(row)), { selected_data }),
      hoverable: true,
      highlight: true,
    })]

  const bar_options_plot = plot({ series, height: 260 })

  const bar_options = h(
    'div',
    {},
    bar_options_plot,
    h(
      pure(({ selected_data }) =>
        h('output', { 'aria-live': 'polite', style: { display: 'block' } }, selected_data.get()),
      ),
      { selected_data },
    ),
  )

  // In Antithesis notebook, plot() returns a Printable. Uncomment below to display it:
  // print(bar_options)
  // presentation.blank("Bar options").print(bar_options)
```

## Stacked bars

Stacked bars divide each bar into segments, showing how individual values
contribute to a total. They make it easy to compare both the totals and their
composition across categories. Pass an array of value-field names to `y` for
vertical stacks or `x` for horizontal stacks. An array of colors assigns one
color to each field, in the same order.

```js folded
    { day: 'Mon', network: 18, compute: 42, storage: 24 },
    { day: 'Tue', network: 24, compute: 32, storage: 18 },
```
