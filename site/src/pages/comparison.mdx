# Comparison

The systems cluster into a few shapes: **styled React libraries** you install
and theme (MUI, Ant Design, Mantine, Carbon, Atlaskit, Blueprint, Astryx,
Gravity), **headless primitives** you style yourself (Radix, Base UI),
**copy-paste collections** you own in your repo (shadcn/ui, Untitled UI), and
**framework-agnostic web components** (Web Awesome, Polaris, Anta). Versions
are a snapshot from {AS_OF}; follow each system's link for the current
release.

<Disclosure title="Frameworks, styling, license">

<ComparisonMatrix />

Most systems here are React-only and style through a runtime or a build step:
CSS-in-JS (MUI, Ant Design, Atlaskit), Sass (Carbon, Blueprint), StyleX
(Astryx), Tailwind (shadcn, Untitled UI). Anta ships web components styled
with plain CSS in a single `@layer`, so there is no style runtime and any
consumer rule overrides a default without a specificity fight.

</Disclosure>

## Component coverage

Grouped by job, so a Dialog / Modal / Drawer family counts as one row. Anta
covers the common controls and is narrower than the batteries-included kits:
no toast, slider, or avatar yet, and the table and plot libraries are still
upcoming. Radix and Base UI leave most visual cells empty by design; they
ship behavior.
