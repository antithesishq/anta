# Switch

Switches change a single setting immediately. Use a checkbox when people select one or more values to submit together.

<Preview minHeight={176} align="center">
  <SwitchPreview client:load />
</Preview>

## Tone

`tone` colours the checked track; the off track stays neutral. Use `neutral` when a setting should not claim semantic importance.

<Preview gap="16px">
  <div style={{ display: 'flex', alignItems: 'center', gap: '8px' }}><Switch defaultChecked tone="neutral" label="Neutral" /><Checkbox defaultChecked tone="neutral" label="Checkbox" /></div>

## Size

`small`, `medium` (the default), and `large` scale the track, thumb, free-area icon, and label together.

<Preview gap="16px">
  <div style={{ display: 'flex', alignItems: 'center', gap: '8px' }}><Switch defaultChecked size="small" label="Small" /><Checkbox defaultChecked size="small" label="Checkbox" /></div>
  <div style={{ display: 'flex', alignItems: 'center', gap: '8px' }}><Switch defaultChecked label="Medium" /><Checkbox defaultChecked label="Checkbox" /></div>
  <div style={{ display: 'flex', alignItems: 'center', gap: '8px' }}><Switch defaultChecked size="large" label="Large" /><Checkbox defaultChecked size="large" label="Checkbox" /></div>
</Preview>

```tsx
<Switch defaultChecked size="small" label="Small" />
<Switch defaultChecked label="Medium" />
<Switch defaultChecked size="large" label="Large" />
```
