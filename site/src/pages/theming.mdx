# Theming

Anta works without a theme. Customize individual components through their props
or with classes in your application CSS.

When an application needs many customizations or a global change to Anta's look
and feel, add a theme stylesheet. Import one theme after the package styles:

```ts
import '@antadesign/anta/theme-antune.css' // Choose one theme included in the package.
```

Antune and the default styles are MIT licensed. The Antithesis theme
(`@antadesign/anta/theme-antithesis.css`) is copyright Antithesis Operations LLC
and has a [separate noncommercial license](https://github.com/antithesishq/anta/blob/main/theme-antithesis-license.md).
Commercial use of that theme requires prior written permission through the
[Antithesis contact page](https://antithesis.com/company/contact/). You can use
Anta commercially under MIT with the default styles, Antune, or your own theme.

<Disclosure title="Fonts in a theme" id="fonts-in-a-theme">

Anta's themes do not load fonts. `tokens.css` defines three system font stacks,
which the optional themes preserve:

```css
:root, .light {
  --sans-serif: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto,
    Oxygen, Ubuntu, Cantarell, "Open Sans", "Helvetica Neue", sans-serif;
  --serif: ui-serif, Georgia, Cambria, "Times New Roman", Times, serif;
  --monospace: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Monaco,
    Consolas, "Liberation Mono", monospace;
}
```

Components and theme rules choose which variable to use. For example, body text
can use `--sans-serif` while a particular title style uses `--serif`. Package
styles do not force font-specific stylistic sets or variable-font axes.

Host your font files in your application and register them in a separate
stylesheet such as `fonts.css`. Load it after Anta's styles and optional theme:

```css
/* fonts.css */
@font-face {
  font-family: "App Sans";
  src: url("/fonts/app-sans.woff2") format("woff2");
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
}

:root {
  --sans-serif: "App Sans", system-ui, sans-serif;
  --serif: Georgia, serif;
  --monospace: ui-monospace, monospace;
}
```

Alternatively, use the [Google Fonts CSS API](https://developers.google.com/fonts/docs/css2)
to load your chosen families. This example includes regular and italic styles:

```css
/* fonts.css: place @import before other rules. */
@import url("https://fonts.googleapis.com/css2?family=Inter:ital,wght@0,400;0,600;1,400;1,600&family=JetBrains+Mono:ital,wght@0,400;0,600;1,400;1,600&family=Source+Serif+4:ital,wght@0,400;0,600;1,400;1,600&display=swap");

:root {
  --sans-serif: "Inter", sans-serif;
  --serif: "Source Serif 4", serif;
  --monospace: "JetBrains Mono", monospace;
}
```

Choose the styles and weights your app uses. Loading Google Fonts makes requests
to Google's servers; self-host font files when you need all assets on your own
origin.

The anta.design website loads its reference fonts through separate
[Antune font CSS](https://anta.design/themes/fonts-antune.css) and
[Antithesis font CSS](https://anta.design/themes/fonts-antithesis.css). These
site stylesheets show the website's font-face declarations, font stacks, and
font-specific axis settings. They are examples of application font setup and
are not imported by the published themes. Use your own font stylesheet and
font sources in your application.

</Disclosure>

<Disclosure title="Text and hint sizes" id="text-and-hint-sizes">

`tokens.css` defines independent font-size and line-height scales for main text
and hints. Matching controls use these values without requiring `reset.css`.
The root text default also uses `--font-size-medium`.
Use length values such as `px` or `rem` for these variables.

| Size | Main font size | Main line height | Hint font size | Hint line height |
| --- | --- | --- | --- | --- |
| Small | `--font-size-small`: 13px | `--line-height-small`: 18px | `--font-size-hint-small`: 12px | `--line-height-hint-small`: 16px |
| Medium | `--font-size-medium`: 15px | `--line-height-medium`: 22px | `--font-size-hint-medium`: 14px | `--line-height-hint-medium`: 20px |
| Large | `--font-size-large`: 17px | `--line-height-large`: 26px | `--font-size-hint-large`: 16px | `--line-height-hint-large`: 24px |

Main text also provides `--font-size-micro` (11px) and `--line-height-micro`
(15px). Tags map small, medium, and large to main micro/tiny/small font sizes
(11/12/13px) and micro/small/medium line heights (15/18/22px). Tag padding
remains component-owned to preserve pill heights.

Compact primary text also has `--font-size-tiny` (12px) and
`--line-height-tiny` (16px). Progress labels and Slider markers map their
small, medium, and large variants to tiny, small, and medium text. Their
12/16, 13/18, and 15/22 pairs remain independent of the hint scale.

MenuGroup and native Select group captions use tiny text at every field
size. Menu Item labels and native Select options use `--font-size-menu-medium`
(14px); their hints use the independent `--font-size-menu-hint-medium` (12px).
These menu font sizes stay fixed across Select field sizes. Menu labels and
wrappers derive leading with `calc(20em / 14)`; hints use `calc(16em / 12)`.
The default pairs are 14/20px and 12/16px, independent of main text and control
hints. Menu separator captions use the menu label font size minus 1px.

The reset makes inline code 1px smaller than its surrounding text. Code blocks
have an independent pair: `--font-size-code-block-medium` (13px) and
`--line-height-code-block-medium` (20px). Code inside them inherits the block's
typography. Changing main text sizes leaves code-block typography unchanged.

Override either scale on the root or an application container. Changing hint
typography leaves main text unchanged:

```css
.settings {
  --font-size-hint-medium: 13px;
  --line-height-hint-medium: 18px;
}
```

Button, Tabs, Steps, Slider labels and values, Input, InputTime, Text, Checkbox, Switch, and Radio options
use the main scale. Field, choice-control, RadioGroup, and Steps hints use the
hint scale. Tooltip uses medium hint typography. Select, InputDate, and
InputAutocomplete inherit their field styles from Input. Native text inputs,
textareas, file inputs, and Select fields use the main scale as well.

Input defines `--input-field-height` on its host (24, 28, and 32px for small,
medium, and large). Both its pre-registration fallback and registered field
use this minimum height. The fallback also accommodates larger inherited text
leading. This field geometry remains independent of typography and action-button
sizing.

RadioGroup labels follow the group's size, matching Input labels. Plain Card
content, Expander details, and Banner messages use medium text. Copy feedback
and Calendar weekday labels use small text. Tags combine main font-size and
line-height steps; Menu Item uses its independent menu typography.
For an individual component, override `font-size` and `line-height` on its
styled element or exposed part. Geometry such as padding and control dimensions
remains component-specific.

</Disclosure>

<Disclosure title="Heading sizes and text compensation" id="heading-sizes">

Title, Expander summaries, native disclosure summaries, and raw headings share
six heading levels. Dialog headers use level 4. Each level uses
`--font-size-heading-N` and `--line-height-heading-N`, where `N` is 1 through 6.

| Level | Font size | Line height |
| --- | --- | --- |
| 1 | 28px | 34px |
| 2 | 24px | 30px |
| 3 | 20px | 26px |
| 4 | 17px | 24px |
| 5 | 15px | 22px |
| 6 | 13px | 18px |

Button and Tabs share label bottom-padding compensation through
`--text-compensation-small` (0.5px), `--text-compensation-medium` (1px), and
`--text-compensation-large` (1.5px). Their outer padding absorbs this amount to
retain control heights. Buttons inside field action slots disable compensation.

</Disclosure>

<Disclosure title="Color seeds" id="color-seeds" data-no-search>

In your custom theme, override any of Anta's six seed color tokens to recolor
components. These overrides can live in any application stylesheet:

- `--anta-seed-neutral`
- `--anta-seed-brand`
- `--anta-seed-info`
- `--anta-seed-success`
- `--anta-seed-warning`
- `--anta-seed-critical`

```css
:root {
  --anta-seed-brand: #0f766e; /* a teal brand; every brand token follows */
}
```

For more control, customize the `--text-*`, `--bg-*`, and `--border-*` tokens
separately for light and dark modes.

Anta's styles use ordered child layers inside `@layer anta`. Your regular
unlayered CSS overrides them without `!important`.

</Disclosure>
